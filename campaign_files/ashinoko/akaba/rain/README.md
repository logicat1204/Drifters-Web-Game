# Recursos de temporada

`dialogue.json` contiene las escenas de diálogo. Las imágenes en `story_start/` y `story_end/` reemplazan esos diálogos.

Carpetas: `music/`, `story_start/`, `story_end/`, `narrative_music_start/`, `narrative_music_end/`, `story_sounds_start/`, `story_sounds_end/`. Se mantiene la ordenación natural y la asociación de sonidos por nombre o número de página.
