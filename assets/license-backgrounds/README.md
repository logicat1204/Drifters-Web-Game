# Fondos de licencia

Guarda cada fondo PNG o WebP de **512 × 512 px** en esta carpeta. Usa un identificador numérico de por lo menos tres dígitos, por ejemplo `001.webp`, `002.png` o `003.webp`. Reserva un solo archivo por identificador y conserva el número al retocar un fondo que ya se pueda seleccionar.

El servidor ordena las imágenes por número. El carrusel empieza con el fondo predeterminado del juego. El retrato de avatar o foto aparece sobre la imagen, de modo que conviene dejar el centro con poco contraste. El editor y la tarjeta principal usan el mismo fondo con un recorte centrado.

Los tres fondos iniciales reutilizan las texturas de cielo de `assets/touge_city_assets/textures/`, recortadas a formato cuadrado.
