# Modelos para el editor de mapas

Copia aquí tus modelos `.glb`. Puedes organizarlos en subcarpetas y usar nombres con espacios o acentos. El editor revisa esta carpeta mientras está abierto y los muestra en **Catálogo → Modelos propios**.

Exporta los modelos como escenas estáticas con la geometría integrada y **Y hacia arriba**. Si el GLB usa imágenes externas, copia también las texturas dentro de esta carpeta y conserva sus rutas relativas. El catálogo admite las mallas trianguladas que puede leer el juego.

Los archivos de mapa guardan referencias al GLB y a sus texturas. Incluye esos archivos junto con el JSON del trayecto al publicar un mapa, y conserva los nombres y las rutas que usaste al colocarlos.
